From 3 objects to 3,000.

Keep the same project structure and operations as your Fabric estate grows.

Start with the data you have

  1. 3

    A few files and a Table.

    Put definitions in source control and make the load repeatable. A small project does not need its own framework.

  2. 30

    Dependencies become worth recording.

    Keep the order with the code rather than reproducing it in pipelines and local conventions.

  3. 300

    Operate the estate together.

    Incremental progress, validation, failure recovery and environment mappings need to work across items, not just within individual scripts.

  4. 3,000

    Repeated overhead matters.

    Weaver schedules independent work together and coordinates the dependencies between Lakehouses, Warehouses and semantic models.

An hour for the first load

A 3,000-object test estate on F64 loaded in about an hour. Later incremental loads completed in under 15 minutes.

The estate contained a Lakehouse and two Warehouses, with billions of row insertions across its layers.
