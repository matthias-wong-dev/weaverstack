Keep the tools you know.

Weaver works with native Power BI projects as well as Fabric Lakehouse and Warehouse items. Power BI-only use does not require a Weaver catalogue.

Choose the work you want to make easier

Lakehouse

Keep your Python.

Manage files and Delta tables, borrow existing data for development, and keep incremental progress with each consumer.

Explore Lakehouse →

Warehouse

Your SQL, with the repetitive engineering already done.

Author the query rather than a load procedure for every table. Inspect changes, row movement and work that is stale or blocked.

Explore Warehouse →

Semantic Models

Start with the model you have.

Deploy native PBIP/TMDL, apply shared conventions and validate the numbers. Fabric integration and model variants are optional.

Explore Semantic Models →

Reports

One report project across environments.

Keep one native project in source control. Resolve development and production names and the linked model at deployment.

Explore Reports →
