Lakehouse, Warehouse, semantic models and Reports.

Weaver works with native Fabric Lakehouse and Warehouse items, as well as Power BI projects.

Keep the languages you use

Lakehouse

Load files and Delta tables with Python or Spark SQL. Track dependencies and incremental progress without maintaining a separate pipeline for each table.

Lakehouse →

Warehouse

Write T-SQL queries. Weaver creates the load procedures, applies row changes and records the result.

Warehouse →

Semantic Models

Deploy native TMDL models, share modelling conventions and compare DAX results with source data.

Semantic models →

Reports

Keep one native Report project across environments. Deployment resolves its workspace, name and linked model.

Reports →

Operate them as one estate

Dependencies connect source data, transformations and semantic-model refreshes. Build, Load and Test use the same project and catalogue; Health reports their current state together.

Workspace configuration keeps physical names out of your source definitions. Python and SQL remain ordinary code, and models and Reports retain their native formats.
