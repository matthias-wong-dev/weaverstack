Warehouse engineering in T-SQL.

Write the query and declare the table. Weaver creates the load procedure, applies changes and records progress.

Keep the transformation as a query

A native SQL comment holds the Table’s identity, keys and schema. Build creates the table and load procedure; Load runs the query and applies the result.

Warehouse/Operations/Parcel.Depot.sql 
/*
Table ID: Parcel.Depot
Description: Delivery depots.
Lineage: A small reference list authored in the project.
Primary key: Depot ID
Schema:
  Depot ID: int
  Depot: varchar(30)
*/
select DepotID as [Depot ID], Depot
from (values (1, 'North'), (2, 'South')) v(DepotID, Depot);
