Start with the model, not an estate

An existing Power BI project can be deployed to its service workspace without first creating a Weaver catalogue or Warehouse. Choose the model’s destination, Build it and inspect the deployed result. The native source stays unchanged.

One rule instead of another manual modelling pass

Hide the many-side relationship keys with a same-name TMDL overlay:

PowerBI/Parcel/Parcel.tmdl 
model Model
    annotation 'Weaver.AutoHideForeignKeys' = true

Weaver applies the rule to the definition it deploys, preserving the native relationship and partitions. Shared policy carries a convention across models; custom Python annotations and composition handle project-specific transformations and variants.

A refreshed measure still needs a check

A DAX Assumption can find an invalid result immediately. When the model reads managed Fabric data, a DAX-to-SQL Test compares its number with an independent source calculation, rather than reproducing the same expression in another measure.
