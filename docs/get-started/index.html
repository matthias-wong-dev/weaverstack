Start with the work you already do.

Deploy an existing Power BI project, or build a small Fabric pipeline. You do not need to learn both to begin.

Use an existing Power BI project

Deploy one native PBIP/TMDL model and linked Report, then refresh the model and inspect the result. A small workspace configuration is enough; you do not initialise a Fabric data estate first.

You need Python 3.11 or later, an appropriate Power BI service licence, an existing workspace and permissions for the supported operations. No catalogue Warehouse, Lakehouse, Spark session or Fabric Environment is required for this standalone route.

Deploy your first model and Report →

Build a small Fabric project

Start with a Warehouse Table and a Test. Check the files, Build the definitions, Load the data and Test the result before adding more controls.

You need a Fabric workspace on suitable running capacity and permission for the tutorial’s catalogue and target Warehouse. Python/Spark work has its own runtime prerequisites; they do not belong in the Power BI route.

Install for the route you choose

The developer installation page owns the supported package target and access checks. Use it before copying either tutorial.
