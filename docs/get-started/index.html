Get started with Weaver

Works natively with Microsoft Fabric. Nothing else to host.

Install Weaver with pip in a Fabric Notebook or your own Python environment. Use your existing Fabric workspaces, compute and permissions, without a separate Weaver service, account or software licence.

Install the package

Weaver supports Python 3.13, as well as Python 3.11 and 3.12.

Install Weaver
python -m pip install --upgrade weaverstack
weaver --version

Check the installed version before running your first project.

Existing Fabric compute and workspace permissions still apply.

Work in Fabric or your own editor

Desktop Python

Use your terminal, VS Code or any Python environment on Windows, macOS or Linux. Write locally and run Build, Load, Test and Health against Microsoft Fabric.

Native Power BI semantic models and Reports deploy without Power BI Desktop or a Windows computer. Weaver deploys Report definitions; it is not a visual Report designer.

Fabric Notebook

Install the same Python package:

Notebook cell
%pip install weaverstack

Then:

Python
import weaver

Weaver can use the Notebook's existing workspace, Spark session and identity. No desktop installation is required.

For repeatable jobs, add Weaver to the attached Fabric Environment rather than relying on a session-scoped installation.

Both

Develop locally, run in Fabric, or move between the two. Your Weaver project doesn't need to be rewritten for a different execution environment.

Start with what you're working on

A Lakehouse table, a Warehouse query or a Power BI project is enough to begin. Pick one to try Weaver.

Try the bundled Sales example

Use an existing disposable workspace in place of Analytics.

Terminal
weaver initialise --workspace Analytics --project-folder ./sales \
  --warehouse Curated --example Sales --non-interactive
cd sales
weaver workflow full
