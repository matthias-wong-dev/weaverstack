Get started with Weaver

Already working with Microsoft Fabric or Power BI?

Weaver works natively in Fabric. No additional platform, orchestration runtime or Weaver licence. Just install it with pip.

Install in minutes

Weaver supports Python 3.13, as well as Python 3.11 and 3.12.

Install Weaver
python -m pip install --upgrade weaverstack
weaver --version

That's the Weaver installation. No additional server or orchestration service to set up.

Existing Fabric compute and workspace permissions still apply.

Installation details →

Work from your computer, Fabric Notebooks, or both

Desktop Python

Use your terminal, VS Code or any Python environment. Write locally and run Build, Load, Test and Health against Microsoft Fabric.

Fabric Notebook

Install the same Python package:

Notebook cell
%pip install weaverstack

Then:

Python
import weaver

Weaver can use the Notebook's existing workspace, Spark session and identity. No desktop installation is required.

For repeatable jobs, add Weaver to the attached Fabric Environment rather than relying on a session-scoped installation.

Both

Develop locally, run in Fabric, or move between the two. Your Weaver project doesn't need to be rewritten for a different execution environment.
